# api-projects

本地项目集合，包含三个可独立运行的项目。

## 目录

| 目录 | 说明 |
|---|---|
| `ChatAPI/` | Go + React 全栈对话应用，自带 Dockerfile 与 compose 配置 |
| `finance-tools/` | 财算坊 · 财务工具箱（静态站点 + Node.js 访问日志服务） |
| `tech-site/` | 极客栈 · 技术站（静态站点，含开发者小工具） |

## 约定

- 不上传 `.env`、数据库、`node_modules` 与构建产物，详见 `.gitignore`
- 部署与运维说明见各项目目录内的文件
